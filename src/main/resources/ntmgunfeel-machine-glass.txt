# NTM Reimagined Arms: textures of NTM's machine models whose clear pixels (alpha below 26) are really empty.
# Everywhere else a clear pixel on a machine's model is glass (a window): a bullet pierces it as glass and a hole
# stays (MachineGlass, server switch bulletMachineGlass). Here go grates, nets, perforated plates and cut-outs, where a
# bullet should fly through. One texture a line, then " # " and why. Shared by every version of the mod.
# Made from the models and textures of NTM NEXT 1.0.3 (2026-10-31): every texture whose drawn triangles cover clear
# pixels, looked at one by one.
